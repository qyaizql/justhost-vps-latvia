У CloudHosting это прописано прямо в условиях, у JustHost сверяйте итог на последнем шаге оформления.

**Лицензия Windows.** Ни у CloudHosting, ни у EDIS Global она не входит в стоимость VPS. CloudHosting ставит образ с пробной лицензией и предлагает купить ключ отдельно или использовать свой, у EDIS младшие KVM Smart и KVM Starter помечены как неподходящие для Windows Server, а для Windows рекомендуют KVM Basic Plus и выше.
